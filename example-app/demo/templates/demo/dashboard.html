Poli Page · Django demo

Every SDK feature, one button each. Powered by django-poli-page.

django_poli_page.client → SimpleLazyObject(PoliPage)

step 1render.pdf — bytes

Fetch the full PDF into memory and stream it back via FileResponse.

step 2render.pdf_stream — chunks

Stream the PDF chunk-by-chunk via StreamingHttpResponse.

step 3render_to_file — disk

SDK free function writes a PDF straight to a temp path.


  


  

    
step 4render.preview — HTML

    
Paginated HTML preview, sandboxed in an iframe.

    
    
  


  

    
step 5render.document — store

    
Store the PDF server-side. Returns a descriptor.no document

    
    

  


  

    
step 6documents.get — redirect

    
Fetch a fresh presigned URL and 302 to it.

    
    

  


  

    
step 7documents.thumbnails

    
Per-page base64 thumbnails as JSON.

    
    

  


  

    
step 8documents.preview

    
HTML preview of the stored document.

    
    
  


  

    
step 9documents.delete

    
Soft-delete the stored document. 204 No Content.

    
    

  


  

    
step 10error handling

    
Deliberately trigger INVALID_VERSION_FORMAT; the view catches PoliPageError and returns JSON.

    
    

  


  

    
CLImanage.py poli_page_render

    
Same render path, exposed as a Django management command.

    
python manage.py poli_page_render \
  --project=getting-started \
  --template=welcome \
  --template-version=1.0.0 \
  --data='{"name":"CLI"}' \
  --output=./welcome.pdf
