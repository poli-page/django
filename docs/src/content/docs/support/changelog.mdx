## Versioning

`django-poli-page` shares its major.minor with the Poli Page API: package `0.13.x` talks to API `0.13` and requires `poli-page>=0.13,<0.14`. Patch numbers are free. A change of the API contract, a new feature, and a raise of the minimum Python or Django version are each a minor.
